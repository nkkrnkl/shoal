# Shoal

Shoal is a Chrome extension that acts as an assistant for working with LLMs. It recommends the right model for each prompt based on task difficulty, flags stale or wasted context in long conversations, helps rewrite prompts, and can be driven by voice through Gemini.

Status: planning. No application code yet.
